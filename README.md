# ox64

🔗 **[ox64.app 바로가기](https://ox64.app)**

지인들끼리 수익률을 겨루는 **모의 선물 트레이딩 플랫폼**.

실시간 시세(바이낸스) 기반으로 롱/숏 포지션을 연습하고, 친구들과 랭킹으로 경쟁합니다.
잔고·포지션·손익은 전부 서버(Cloudflare D1)가 계산·보관하므로, 클라이언트에서 가격이나
잔고를 조작해도 랭킹에는 반영되지 않습니다 — 공정한 경쟁을 위한 **서버 권위 구조**입니다.

## 주요 기능

- 📈 **실시간 차트** — TradingView Lightweight Charts, 38개 실제 심볼 + 가상 심볼(OX/USDT · EW/USDT) 40종, 다양한 타임프레임(초/분/시간/일+)
- 🎨 **차트 색상 테마** — 바이낸스 / OKX / 트레이딩뷰 배색 프리셋(캔들 색·배경), 사이트 다크/라이트/고대비 테마와 별개로 선택
- 📊 **보조지표** — EMA / Bollinger Bands / RSI(기간·개수 자유 설정), 거래량 히스토그램
- 🏷️ **거래 수수료 · VIP 등급(무한 레벨)** — 누적 거래대금(레버리지 포함)이 쌓일수록 등급이 계속 오른다. 한 등급당 필요 거래대금 ×4 · 수수료 ×0.79 (VIP0 0.03% → VIP10 0.0028% → VIP20 0.00027% → … 하한 0.0000001%), 상한 없음. 등급 뱃지(클릭 시 다음 등급까지 진행 막대·남은 거래대금·등급표)와 주문 예상 수수료 표시
- 💰 **모의 거래** — 시장가/지정가/조건부(스탑) 롱·숏, 레버리지 1~200배, SL/TP, 부분청산, 강제청산(계좌 파산) + 리필 안전망
- 🔢 **수량 제한 없음(사실상)** — 싼 코인을 고배율로 담으면 수량이 조 단위를 훌쩍 넘는데, 예전엔 1,000조(1e15)를 넘기면 "수량 오류"로 막혔습니다. 이제 한도는 **가용 증거금뿐**이라 감당 가능한 만큼은 얼마든지 주문할 수 있고(부족하면 "증거금이 부족합니다"), 그렇게 커진 포지션도 전량 청산 시 먼지 없이 깨끗하게 닫힙니다
- 🎯 **조건부(스탑) 주문** — 현재가가 지정한 트리거 가격 이상/이하가 되면 시장가로 진입. 물량이 부족해 일부만 체결되면 나머지는 조건이 계속 살아있습니다
- ♾️ **무한(반복) 조건부** — "1.5 이하로 떨어지면 계속 123개씩 매수"처럼 체결돼도 주문이 사라지지 않고 계속 일합니다. 두 가지 방식:
  - **조건 만족 중 계속**(기본) — 트리거 조건이 참인 동안 계속 진입합니다(물타기/DCA). 재실행 간격은 **최소 5초**입니다. ⚠ 스스로 멈추지 않으니 **재실행 간격(초)** 과 **최대 실행 횟수**로 제어하세요
  - **되돌아올 때마다 1회** — 한 번 실행하면 쉬고, 가격이 트리거 반대편(재무장 가격)으로 돌아왔다 다시 트리거될 때 1회씩 실행합니다
  - **앱을 완전히 닫아둬도 계속 실행됩니다**(서버 cron 이 1분마다 전 유저의 조건을 평가 — 지정가·SL/TP 도 동일). 평가 주기만 달라집니다: 앱을 켜두면 약 1초, 닫아두면 1분마다 몰아서. 조건부 탭에서 언제든 **수정·취소**할 수 있습니다
- ✏️ **조건부 주문 수정** — 취소하지 않고 트리거 가격·수량·조건(이상/이하)·반복 설정을 바로 고칩니다
- 🪙 **가상 코인(OX/USDT · EW/USDT)** — 실제 코인과 완전히 동일한 레버리지 거래, 체결가만 마켓메이커 봇이 생성. 코인마다 봇 심리·호가창·캔들·체결이 완전히 독립이라 서로 다르게 움직입니다. 호가 단위는 실제 거래소처럼 **유효숫자 4자리**로 고정돼 가격대에 따라 자동으로 바뀝니다(0.9234 → 0.0001 / 0.002434 → 0.000001 / 123.4 → 0.1)
- 🧠 **봇 심리 모델** — 추세 지속·변동성 클러스터링·과열 후 되돌림·탐욕/공포 국면 전환(급락이 급등보다 빠름)·라운드넘버 지지저항까지 재현해, 밋밋한 랜덤워크가 아니라 읽을 구조가 있는 차트를 만듭니다
- 📖 **호가창 · 체결내역** — 매수/매도 좌우 2열 호가, 실시간 체결 탭(실제 심볼은 바이낸스 체결 스트림). OX 호가는 사람처럼 1.4000 같은 라운드 가격에 몰리고 그 자리에 두꺼운 벽이 생깁니다. 내가 걸어둔 미체결 주문은 호가창에서 강조 표시
- 🏆 **친구 랭킹** — 평가자산(잔고 + 미실현 손익) 기준 실시간 순위 + 거래소가 수수료로 번 총액
- 🔐 **간편 로그인** — 이름 + 패스코드만으로 가입/로그인
- 📱 **반응형 UI** — 모바일 1줄 헤더 + 아이콘 위주 컴팩트 레이아웃, PC 확장 레이아웃
- 🧩 **[ox64.app/b 보석찾기](https://ox64.app/b)** — 코인 트레이딩과 완전히 분리된 미니 퍼즐게임. 격자에 숨은 보석을 칸 단위로 찾아내는 방식(레벨 1~10, 칸 오픈마다 코스트 소모·클리어 시 재화 보상). 같은 계정(이름+패스코드)을 그대로 쓰지만 재화·기록은 트레이딩과 무관한 별도 D1 테이블
- 🛰️ **[ox64.app/s1 미니 RTS](https://ox64.app/s1)** — 스타크래프트1 스타일 실시간 전략 게임. 일꾼으로 자원을 캐고 기지를 올려 컴퓨터와 1:1로 붙습니다(테란 1종족, 유닛 4종·건물 5종, 전장의 안개). 사이트에서 유일하게 **서버도 로그인도 없이 전부 브라우저에서** 돌아갑니다 — RTS는 초당 수십 번 시뮬레이션이 필요해 D1 폴링으로는 불가능하기 때문입니다. 그래픽은 전부 코드로 그린 도형이고 원본 리소스는 쓰지 않았습니다
- ⏱️ **[ox64.app/5m 5분 던전](https://ox64.app/5m)** — 보드게임 "5-Minute Dungeon"을 재현한 실시간 협동 카드게임. 방 코드로 친구들과 모여(최대 4인) 손패의 아이콘 카드를 맞춰 몬스터·함정·보스를 돌파, 5분 벽시계 안에 던전을 클리어합니다. 영웅 6종(각자 1회용 특수 능력)·던전 4개(난이도별)·몬스터 24종, 인원수에 따라 난이도가 자동 조정됩니다. Durable Objects 없이 D1+짧은 폴링(진행 중 0.5초)으로 동기화 — 무료 플랜 유지

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| 프론트엔드 | Vite + React (TypeScript), Zustand, Tailwind CSS |
| 차트 | TradingView Lightweight Charts v4 |
| 실시간 시세 | RxJS + Native WebSocket (바이낸스 스팟) |
| 백엔드 | Cloudflare Pages Functions (`functions/`) |
| DB | Cloudflare D1 (SQLite) |
| 인증 | HMAC 서명 세션 쿠키 + PBKDF2 패스코드 해싱 |
| 백그라운드 작업 | 별도 Cron Worker (`cron/`) — 강제청산·지정가·SL/TP·조건부 체결 + OX 마켓메이커 봇을 접속자 없이도 1분마다 실행 |
| 미니 RTS (`/s1`) | Canvas 2D + 자체 시뮬레이션 루프(고정 틱 30Hz) + 그리드 A* — 서버 없음 |

프론트(정적 SPA)와 백엔드(Pages Functions)를 **한 레포·한 배포**로 운영합니다(단, Pages 는 정기 실행을
지원하지 않아 `cron/` 만 별도 Workers 프로젝트로 배포). 커스텀 도메인(`ox64.app`)만 접속되도록 `*.pages.dev`
는 자동 리다이렉트됩니다.

## 왜 서버 권위 구조인가

클라이언트(브라우저 저장소)에 잔고나 시세를 두면 콘솔로 얼마든지 변조할 수 있어 랭킹 경쟁이
무의미해집니다. 그래서 체결가 조회, 증거금 계산, 손익 정산을 모두 서버가 수행하고 D1에
원자적으로 기록합니다. 클라이언트가 보내는 값은 `symbol / side / size / leverage` 뿐이며,
가격은 서버가 직접 거래소에서 받아옵니다.

## 시작하기

```bash
npm install
npm run dev              # 프론트 개발 서버 (Vite) — /api 는 동작하지 않음

npm run build            # tsc -b && vite build → dist/
npx wrangler pages dev dist   # 백엔드(D1 + Functions) 포함 로컬 구동
```

D1 스키마 적용:

```bash
npx wrangler d1 execute ox64 --remote --file=./schema.sql
```

자세한 폴더 구조, 데이터 흐름, 배포 설정은 [`CLAUDE.md`](./CLAUDE.md)를 참고하세요.
